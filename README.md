# Smart Student Progress Tracker (Console Version)
This is a console based application developed using C++ as end semester project for our course.

## Features
It has following features:
- Study session tracking
- Level and XPs
- Hardcoded timetable display
- Exam Tracker
- Deadline Tracker/Manager
- Data storage using file handling
- Syllabus completion predictor 

## Tools and Techs Used
- C++
    - Object-Oriented Programming
    - File Handling
    - Arrays & Structures
    - Recursion
